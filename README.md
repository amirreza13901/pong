# Pygame Pong

Hello everyone! 

To play, just run the `main.py` file. The assets must be in the `assets` folder in the same directory as the `main.py` and the other `.py` files. Enjoy!

### 🎮 How to Play
*   Move with the **Up** and **Down** arrow keys (or W/S).
*   First to **5 points** wins!
